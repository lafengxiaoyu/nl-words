# 🎮 单词拼写挑战游戏

## 功能介绍

这是一个全新的趣味性背单词游戏，通过拼写挑战来提高荷兰语单词记忆效果！

### ✨ 核心功能

1. **智能拼写挑战**
   - 根据中文/英文翻译拼写荷兰语单词
   - 根据单词熟悉度自动调整提示难度
   - 实时反馈和错误纠正

2. **生命值系统**
   - 每个玩家有3条命
   - 答错或超时会失去1条命
   - 生命值为0时游戏结束

3. **连击奖励系统**
   - 连续答对获得连击加成
   - 连击越高，得分倍率越高
   - 答错会重置连击

4. **提示系统**
   - 根据单词熟悉度提供不同级别提示
   - 新词：显示更多字母
   - 已掌握单词：提示更少
   - 可多次使用提示逐步揭示答案

5. **限时模式**（可选）
   - 10秒/15秒/20秒三种难度
   - 倒计时动态效果
   - 时间到自动判错

6. **难度选择**
   - A1-A2 / B1-B2 / C1-C2
   - 可选择单词数量（5/10/15/25）
   - 根据个人水平调整挑战难度

7. **成绩统计**
   - 实时显示得分、进度、生命值
   - 游戏结束后展示详细统计
   - 错误单词回顾和学习

8. **进度同步**
   - 自动更新用户学习进度
   - 记录测试正确率
   - 影响单词熟悉度计算

## 如何使用

### 1. 启动开发服务器

```bash
cd web
npm run dev
```

### 2. 访问游戏页面

在浏览器中打开：
- `http://localhost:5173/zh/game` （中文版）
- `http://localhost:5173/en/game` （英文版）

或者点击导航栏的"玩游戏"按钮。

### 3. 开始游戏

1. 选择难度等级（A1-A2/B1-B2/C1-C2）
2. 选择单词数量（5/10/15/25）
3. 选择限时模式（可选）
4. 点击"开始挑战"

### 4. 游戏进行

1. 查看单词的中文/英文翻译
2. 点击🔊按钮听发音
3. 在输入框中拼写荷兰语单词
4. 如需提示，点击"使用提示"
5. 按Enter或点击"提交答案"
6. 查看结果，点击"下一题"

### 5. 查看结果

- 游戏结束后会显示：
  - 最终得分
  - 正确率
  - 错误单词回顾
  - 可重新开始或返回学习

## 游戏机制

### 得分计算

```
基础分 = 10分
连击加成 = 连击数 × 2
总得分 = 基础分 + 连击加成
```

例如：
- 第1题正确：10分
- 第2题正确（连击1）：10 + 2 = 12分
- 第3题正确（连击2）：10 + 4 = 14分
- ...

### 提示系统

根据单词熟悉度提供不同提示：

| 熟悉度 | 提示级别1 | 提示级别2 | 提示级别3 |
|--------|-----------|-----------|-----------|
| 新词 | 首字母 + _... + 末字母 | 首两字母 + _... + 末两字母 | 完整单词 |
| 学习中 | 首字母 + _... + 末字母 | 首两字母 + _... + 末两字母 | 完整单词 |
| 熟悉 | 首字母 + _... | 首两字母 + _... | 完整单词 |
| 已掌握 | 首字母 + _... | 完整单词 | - |

### 生命值规则

- 初始生命值：3
- 答错：失去1条命
- 限时模式下超时：失去1条命
- 生命值为0：游戏结束

### 连击规则

- 连续答对：连击+1
- 答错或超时：连击重置为0
- 连击越高，每次得分越高

## 自定义配置

### 修改默认时间限制

在 `SpellingGame.tsx` 中找到：
```typescript
const [timeLimit, setTimeLimit] = useState(15) // 默认15秒
```

修改为你想要的时间（秒）。

### 修改默认单词数量

在 `SpellingGame.tsx` 中找到：
```typescript
const [wordCount, setWordCount] = useState(10) // 默认10个词
```

### 修改连击加成倍率

在 `SpellingGame.tsx` 中找到：
```typescript
const bonusPoints = 10 + (combo * 2) // 连击加成 × 2
```

修改 `2` 为你想要的倍率。
